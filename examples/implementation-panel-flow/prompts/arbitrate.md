# Arbitrate The Preferred Path

Create `examples/implementation-panel-flow/artifacts/ARBITRATOR_SYNTHESIS.md`
with `striatum.synthesis.v1` front matter:

```yaml
---
schema_version: striatum.synthesis.v1
artifact_kind: synthesis
---
```

Select one option, reject all options, or compose a hybrid path. Base the choice
on the problem brief, proposals, scorecards, and tradeoff ledger. Explain:

- The selected path.
- Why it beats the alternatives.
- Conditions that would change the decision.
- Follow-up work required before implementation.

If this job is reached after a dissent cycle, address the dissent findings
explicitly.
