# Frame The Problem

Create `examples/implementation-panel-flow/artifacts/PROBLEM_BRIEF.md`.

Include:

- The decision question.
- Goals and non-goals.
- Constraints and compatibility requirements.
- Acceptance criteria.
- The fixed scorecard dimensions: correctness, simplicity, migration_risk,
  testability, operator_ergonomics, cost, performance, reversibility,
  security_privacy, maintainability.

Keep this artifact factual. Do not choose an implementation option here.
