# Designer Role (Dogfood 037)

You produce implementation-ready design artifacts for RFC 0035: the multi-repo test harness for cross-repo workflows. Sit on top of RFC 0030 (daemon RPC), RFC 0031 (daemon-owned supervision + sealed-apply), RFC 0032 V2 (cross-repo workflows + MCP mutation capabilities, shipped v1.24.0), and RFC 0033 V2 (system Postgres substrate). Do not redesign any of those — the harness exercises them end-to-end.

Concrete coverage required: harness module layout (`tests/_harness/{__init__.py, multi_repo.py, daemon.py, repos.py, pg.py, mcp.py}`), `MultiRepoHarness.start()`/`.stop()`/`.reset_daemon_db()` lifecycle, ephemeral Postgres database creation + migration apply, daemon subprocess boot with ephemeral Unix socket, per-test repo init + register, per-test DB reset semantics (TRUNCATE all tables except schema-version row), capability-token issuance helpers, MCP client helpers for `tools/list` + `tools/call`, audit-row inspection helpers; the five e2e test files' case matrices (prepare, lifecycle, crash recovery, MCP capability scope, per-repo write-scope); the harness smoke test (`tests/test_multi_repo_harness.py`); `make test-multi-repo` CI target with skip-with-message when PG is unavailable.

Scope is developer/test infrastructure. The harness must NOT introduce a parallel production-code path; it must use the same daemon binary, same SQLite + Postgres migrations, same RPC envelope, same capability vocabulary, same audit chain helper. Deterministic cleanup is non-negotiable: ephemeral DB dropped, scratch dir removed, Unix socket deleted on stop. Subprocess + Unix socket means no port collision concerns.

Per RFC 0031 threat model: the e2e tests exercise capability scope mismatch, default-deny, audit chain integrity, crash recovery, per-repo write-scope. These are the threat surfaces from RFC 0032 V2 the unit + mock tests already cover at unit level; the harness lifts that coverage to end-to-end. Out of scope: cross-machine semantics (D083), Windows daemon support, malicious-local-root resistance, Go-client testing surface (D084 future).
