### `install`

```python
def install(
    *,
    target: Path,
    profile: str,                    # "claude_code" | "generic"
    scope: str = "project",          # "project" | "user"
    namespace: str = "striatum-",
    force: bool = False,
    dry_run: bool = False,
) -> dict[str, Any]:
    """Render templates for ``profile`` into the target tree.

    Returns ``{"profile", "scope", "namespace", "files": [
        {"path", "status", "sha256_before", "sha256_after"}
    ], "manifest_path"}`` where ``status`` is one of
    ``written | skipped_unchanged | refused_modified | dry_run``.
    """
```

`scope="user"` rewrites the target prefix:

- `claude_code, project` → `<target>/.claude/skills/<ns>striatum-<skill>/`
- `claude_code, user` → `${HOME}/.claude/skills/<ns>striatum-<skill>/`
- `generic, project` → `<target>/<ns>STRIATUM_AGENT_GUIDE.md`
- `generic, user` → `${HOME}/<ns>STRIATUM_AGENT_GUIDE.md`

The default `target` is the operator's `--repo` argument. The
function never resolves `target` against `os.getcwd()`.

### Manifest schema (`striatum.skills.manifest.v1`)

```json
{
  "schema_version": "striatum.skills.manifest.v1",
  "striatum_version": "0.5.0",
  "generated_at": "2026-05-08T19:00:00Z",
  "profile": "claude_code",
  "namespace": "striatum-",
  "scope": "project",
  "files": [
    {
      "path": ".claude/skills/striatum-workflow/SKILL.md",
      "sha256": "<rendered file sha256>",
      "template": "claude_code/striatum-workflow.md.tmpl",
      "template_sha256": "<unrendered template sha256>"
    }
  ]
}
```

The manifest itself is excluded from `files` (it is its own
self-description). `files` is sorted by `path` so a re-install
produces byte-identical output.

Manifest path:

- `claude_code, project` → `<target>/.claude/skills/<ns>striatum-workflow/.manifest.json`
- `claude_code, user` → `${HOME}/.claude/skills/<ns>striatum-workflow/.manifest.json`
- `generic, project` → `<target>/<ns>STRIATUM_AGENT_GUIDE.manifest.json`
- `generic, user` → `${HOME}/<ns>STRIATUM_AGENT_GUIDE.manifest.json`

### Renderer

`render_template(name: str, context: Mapping[str, Any]) -> str`. V1
uses Python's `str.format_map(context)` with a curated
`MissingKeyDict` so a typo in a template surfaces as a
`StriatumError` (not silent passthrough). The context shape is:

- `striatum_version: str` — `striatum.__version__`.
- `verbs: dict[str, str]` — flat map of `"register-session"` →
  one-line summary, derived from a hand-curated whitelist (the
  research doc's verb table). The whitelist lives in
  `striatum/skills/context.py`; promoting to parser-walked is a
  V1.5 follow-up.
- `front_matter_kinds: list[str]` — sorted
  `striatum.artifacts.ALLOWED_ARTIFACT_KINDS`.

Generated header line, identical across templates:

```
<!-- Generated by striatum {striatum_version}. Regenerate with `striatum skills install`. -->
```

### CLI surface

```text
striatum skills install
  [--profile {claude_code, generic}]   # default: claude_code
  [--scope {project, user}]            # default: project
  [--namespace <prefix>]               # default: striatum-
  [--force]
  [--dry-run]
  [--json]
```

`--target` is intentionally omitted from V1; `--repo` already
specifies the target tree. Profile `all` is deferred (V1.5).

`striatum init [--with-skills [profile]]` runs `init` first; when
the flag is present (with or without a value) it then calls
`install(...)` with `profile=value or "claude_code"` and the
`--repo` directory as `target`. Default scope is `project`. The
JSON envelope on a `--with-skills` invocation includes both the
`init` result and the `install` summary.

### Doctor checks

Two new entries in the structured doctor output:

- `skills_missing` — manifest exists, but at least one
  `files[].path` is absent on disk.
- `skills_outdated` — `manifest.striatum_version <
  striatum.__version__` OR a packaged template's bundled SHA256
  differs from the manifest entry's `template_sha256`.

Both surface a `recovery_command` of the exact `striatum skills
install` invocation that would fix the condition. Doctor never
auto-regenerates.
