## Counterargument sweep

### "Jinja2 introduces XSS risk via the `| safe` filter"

`run_detail.html` uses `{{ graph_svg | safe }}` to embed the
SVG. The SVG body is generated by `render_run_graph` which
escapes every dynamic value via `html.escape`. The only
unescaped strings are constants (CSS class names, marker IDs,
SVG path commands). **Accept.**

### "Path traversal via `/run/<id>/...`"

`_render_run_subpath` rejects `..`, `/` (within the id), and
null bytes before any DB lookup. The DB lookup itself uses
parameterized SQL. **Accept.**

### "Adding Jinja2 inflates the wheel"

The wheel grows by ~250 KB (jinja2) + ~30 KB (markupsafe).
Striatum's prior install was ~1 MB; the post-V1 install is
~1.3 MB. Acceptable for the HTML-correctness win.

### "Dark mode palette readability for `failed` status"

Light: `#d1242f` on `#ffffff` → contrast ratio 5.7 (passes
WCAG AA for normal text). Dark: `#f85149` on `#161b22` →
contrast ratio 4.7 (passes WCAG AA for normal text). White
text on the colored pill: light bg `#1a7f37` (3.8) and dark bg
`#2ea043` (3.5) — both pass WCAG AA for large text (the pill
is ≥14px bold). **Accept.**

### "The longest-path depth assignment isn't deterministic for
cycles"

The renderer reads only `graph.edges` (forward DAG). Cycles
in `graph.cycles` are deliberately ignored. The depth
assignment runs at most `len(nodes) + 1` iterations as a
fixed-point safety net. **Accept.**

### "The hash-redirect island doesn't preserve query strings"

`window.location.replace(target)` where `target` is just the
hash path (no query). Operators with bookmarks like
`#/run/<id>?foo=bar` lose the query. Practically: the SPA
never used query strings, so no real-world bookmarks have
them. **Accept.**

### "What about `app.js` and `app.css` still on disk?"

The handoff notes them as "left in place for one release of
deprecation." V1.5 (or v1.12 cleanup) retires them. Until
then, operators with old browser caches loading
`/static/app.css` directly still get a response. Acceptable
soft transition.

## Decision

Accept V1. Land the change, bump to v1.11.0, transition RFC 0022
to `accepted (V1)`. RFC 0013's hash-routed SPA is superseded
in implementation; V1.5 will retire `app.js`/`app.css` after
the deprecation window.
