# Close Packet Evidence

Read the work packet first and use the exact `author:` line supplied in
`expected_artifacts`.

Write `docs/operator/artifacts/rfc-0040-packet-evidence-closure/CLOSURE.md`
summarizing:

- residual classification;
- source/test changes or explicit no-op rationale;
- workflow validation result;
- test commands and outcomes;
- shared TODO/ROADMAP/BRIEF updates the operator should make later.

Do not edit `docs/TODO.md`, `docs/ROADMAP.md`, or `docs/operator/BRIEF.md`.
