# Gate 0079 — Go-only operability & install

Implement RFC 0079. Read `docs/rfcs/0079-go-only-operability-and-install.md`
in full first; it is the contract. Also read the current `Makefile`,
`go/cmd/striatum/`, `go/pkg/cli/localcommands/`, and
`~/.config/systemd/user/striatumd.service` (the hand-fixed unit to formalize).

## Build (stay strictly in write scope)

1. Add a local `striatum daemon install|uninstall|status` command (in
   `go/pkg/cli/localcommands/` + wired through the existing local-command
   dispatch — do NOT touch daemon RPC routes or `contracts/`). `install`
   renders `~/.config/systemd/user/striatumd.service` from an embedded template
   using systemd specifiers `%h`/`%t` (no hardcoded home paths), scaffolds a
   commented `~/.config/striatum/daemon.toml` only when absent (never overwrite
   a real DSN), runs `systemctl --user daemon-reload` + `enable --now` unless
   `--no-start`, and prints resolved socket/token/MCP-endpoint paths.
   `uninstall` disables/stops/removes the unit (leaving data). `status`
   summarizes unit state + doctor. Non-systemd hosts get a foreground recipe,
   not a hard error.
2. Canonicalize the socket to `${XDG_RUNTIME_DIR}/striatum/daemon-go.sock`; make
   sure nothing you add references `striatumd.sock` or `src/striatum/_daemongo`.
3. Rewrite root `Makefile` `install` to: build → install binaries →
   `striatum daemon install --no-start` → `striatum skills install` → start +
   `doctor` check; add `make uninstall`.
4. Docs: rewrite `docs/GETTING_STARTED.md` to the Go-only clone→`make install`
   →`doctor` path; add `docs/operator/DAEMON_RUNBOOK.md` (lifecycle, runtime
   layout, daemon.toml DSN, `journalctl --user -u striatumd`, troubleshooting);
   update `docs/INDEX.md` and `docs/DOC_MAP.md`.

## Validate
```bash
cd go && go build ./... && go vet ./... && go test ./pkg/cli/... ./cmd/striatum
striatum daemon status   # after a dry render; do not disrupt the running daemon
```
Do not stop/restart the operator's running daemon during the gate; test unit
rendering to a temp path if needed.
