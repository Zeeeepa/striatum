# Gate 0080 — Test & build hardening

Implement RFC 0080. Read `docs/rfcs/0080-test-and-build-hardening.md` in full
first; it is the contract. Also read `go/pkg/db/*_test.go` (the
`STRIATUM_PG_TEST_URL` skip gates), `.github/workflows/ci.yml`, `go/Makefile`,
and the `complete` write-scope guard in `go/pkg/mutations/`.

## Build (stay strictly in write scope)

1. Add `go/pkg/pgtest`: a reusable harness exposing `pgtest.DB(t)` that
   provisions an isolated database (transaction-rollback per test by default;
   template-clone where migrations are under test), applies migrations, and
   returns a ready `db.Runner`. It reads `STRIATUM_PG_TEST_URL` and `t.Skip`s
   when unset.
2. Repoint the existing live-PG tests (`pkg/db`, and other PG-gated tests) onto
   `pgtest`. Reinstate the load-bearing rows RFC 0078 retired-not-replaced
   (recovery causes, capability denial matrix, publish-artifact lane-attestation
   path, migration invariants) as Go integration tests on the harness.
3. CI: in `.github/workflows/ci.yml`, provision a PostgreSQL service, create a
   test role/db, export `STRIATUM_PG_TEST_URL`, and run the suite so live-PG
   tests EXECUTE. Add required `go vet ./...`, `go test -race ./...`, and
   `golangci-lint run` (set: govet,staticcheck,errcheck,ineffassign) steps, plus
   a coverage profile with a floor on core packages. Add matching `go/Makefile`
   targets (do NOT edit the root `Makefile` — that is Gate 0079's scope).
4. Fix the `complete` write-scope guard to BASELINE-DIFF: snapshot tracked/
   untracked at packet claim, flag only paths the lane created/modified outside
   `allowed_paths` — not pre-existing untracked paths. Add a regression test.

## Validate
```bash
cd go && go vet ./... && go test -race ./... && go build ./...
# with a test DSN exported, live-PG tests must RUN (not skip) and pass
golangci-lint run ./... 2>/dev/null || true
```
