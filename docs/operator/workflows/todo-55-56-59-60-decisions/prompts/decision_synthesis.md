# Synthesize Blocked Decisions

Read the work packet first and use the exact `author:` line supplied in
`expected_artifacts`.

Read the four analysis artifacts and produce one checkpoint brief for the
human principal. For each TODO item, include:

- the decision question,
- viable options,
- evidence and tradeoffs,
- implementation impact,
- the recommended option if one is justified,
- the exact decision text the human could accept or modify.

Do not record a decision and do not update `docs/DECISION_LOG.md`.
