# Gate C — Generators: port the two Python generators to Go

You are the implementer for RFC 0078 Gate C. Read first:
`docs/operator/plans/rfc-0078-remaining-work.md` (Gate C),
`scripts/generate_go_rpc_registry.py`,
`scripts/generate_daemon_method_tables.py`,
`go/pkg/cli/routergen/main.go` (the existing Go generator pattern),
`go/pkg/rpc/registry.go` + `go/pkg/rpc/registry_methods.go`,
`docs/architecture/DAEMON_METHOD_TABLES.md`, and
`contracts/daemon_methods.json` (the single source the generators consume).

## Decision (already made — do not re-litigate)

`routes_generated.go` already uses a Go generator (`go run ../routergen`). The
two Python stragglers — `generate_go_rpc_registry.py` (emits
`registry_methods.go`) and `generate_daemon_method_tables.py` (emits
`docs/architecture/DAEMON_METHOD_TABLES.md`) — read the same
`contracts/daemon_methods.json`. **Port both to Go**, mirroring `routergen`.

## Steps

1. Add a Go generator (extend `routergen` or add a sibling `go/pkg/...`
   `main` tool) that reads `contracts/daemon_methods.json` and emits:
   - `go/pkg/rpc/registry_methods.go` byte-identical to today's tracked file;
   - `docs/architecture/DAEMON_METHOD_TABLES.md` byte-identical to today's
     tracked file (preserve the `<!-- Code generated by ... -->` header but
     point it at the Go generator).
2. Rewire the `//go:generate` directives:
   - `go/pkg/rpc/registry.go`: replace the `python3 scripts/generate_go_rpc_registry.py`
     directive with the Go generator.
   - Add/adjust the method-tables directive to invoke the Go generator.
3. Confirm round-trip: `cd go && go generate ./... && git diff --exit-code`
   must be clean (generator reproduces tracked output exactly).
4. Keep `go/pkg/rpc/registry_contract_test.go` as the parity guard (do not
   weaken it).
5. Delete `scripts/generate_go_rpc_registry.py` and
   `scripts/generate_daemon_method_tables.py`.

## Constraints

- Output must be byte-identical to current tracked artifacts — this is a
  generator port, not a format change.
- Stay within `write_scope.allowed_paths`.
